description=Fast solar radiation and photovoltaic potential maps from elevation models, with GPU acceleration
about=Compute clear-sky solar irradiation and photovoltaic potential directly
    inside QGIS from any digital elevation model (DEM). Choose a single-day
    irradiation map (beam, diffuse, reflected, global, sunshine duration) or
    an annual PV potential map with custom panel efficiency. Built for large
    rasters: computation streams through memory-bounded tiles and a GPU path
    speeds annual whole-year simulations by an order of magnitude — a
    1000×1000 annual run takes seconds instead of minutes. Terrain shadowing,
    slope and aspect effects, atmospheric turbidity (Linke) and ground albedo
    are all modeled; slope and aspect are derived automatically from the DEM
    when not supplied. Runs on CPU alone if no GPU is present.

    Requires the Python package sun-solar-radiation (0.1.1 or newer) in
    QGIS's Python. Windows: in the OSGeo4W Shell run
    "pip install sun-solar-radiation". macOS: run
    "/Applications/QGIS.app/Contents/MacOS/python -m pip install sun-solar-radiation".
    Linux: run "python3 -m pip install --user sun-solar-radiation". Then
    restart QGIS. Packages exist for Windows x64, macOS Apple Silicon and
    Linux x86_64; see the README for details.
